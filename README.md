## 2. AI 产品经理为什么值得学

知识助手答错，可能是资料过期、表格解析丢失、分块切断条件、必要内容未召回，也可能是生成没有忠实使用证据。需要沿着下面的链路定位：

**资料 → 解析 → 分块 → 检索 → 回答 → 引用核对**

[上游 README](https://github.com/infiniflow/ragflow/blob/271f601ca2e561d1aaf932ee86e14412b6890df1/README.md)介绍了复杂文档处理、模板化分块、可追溯引用、检索与重排，也扩展了 Agentic Retrieval。本期先学习基础证据链，不把多步检索作为默认答案。

## 3. 三个值得重点检查的环节

### 分块结果：知识是否完整进入系统

检查名称、版本、表格表头及限制条件是否保留。例如“管理员可导出”和“仅企业版适用”被拆开后，只召回前半句会误导用户。

[分块管理文档](https://github.com/infiniflow/ragflow/blob/271f601ca2e561d1aaf932ee86e14412b6890df1/docs/guides/dataset/chunk_parsing_results_and_knowledge_fragment_management.md)说明了查看、编辑、启用与停用分块的能力。人工修补能帮助验证原因，但还要考虑资料更新后如何避免重复修补。

### 检索测试：证据能否排到前面

逐条看来源、内容完整性、日期与版本，不只看相似度分数。

[检索测试文档](https://github.com/infiniflow/ragflow/blob/271f601ca2e561d1aaf932ee86e14412b6890df1/docs/guides/dataset/retrieval_testing.md)涉及阈值、向量权重、重排、元数据过滤与返回数量。提高阈值可能减少噪声，也可能漏掉必要证据；重排可能增加延迟。

### 实际应用：配置是否生效

测试页参数**不会自动同步到 Chat Assistant 或 Agent**。测试页效果好之后，要核对实际应用配置并重跑验收题。

## 4. 原创纸面练习：产品帮助中心

无需软件、账号或公司文件。下面产品、规则与文档均为虚构，不代表 RAGFlow 的实际功能或权限。

先准备四份小资料，保留编号、版本、生效日期：

| 文档 | 虚构内容 |
| --- | --- |
| A | 星河协作操作说明 v2，自 2026-10-01 生效；日志保留 30 天，导出为 CSV |
| B | 操作说明 v1，仅适用于 2026-09-01 至 09-30；日志保留 7 天 |
| C | 权限说明，自 2026-09-01 生效；所有者、管理员可导出，普通成员不可导出 |
| D | 当前目录只含登录、成员管理、日志导出；未说明 SSO 上线时间或延长保存期价格 |

为八道题标注标准答案和必要证据：

| 题目 | 预期与必要证据 |
| --- | --- |
| 现在日志保留多久？ | 30 天，A |
| 9 月 15 日适用什么保留规则？ | 7 天，B |
| 普通成员能导出吗？ | 不能，C |
| 导出是什么格式？ | CSV，A |
| 现在谁能导出、保留多久？ | 所有者与管理员、30 天，A+C |
| 管理员下载操作记录，得到什么文件？ | CSV，A+C；检查口语表达匹配 |
| SSO 什么时候上线？ | 证据不足，无法确认 |
| 延长到 90 天多少钱？ | 证据不足，无法确认 |

逐题检查纸面分块是否保留完整信息。多证据题只召回一段正确内容还不够；统一过滤成“当前版本”会损害历史问题的回答。

交付记录：问题、标准答案、必要证据、预期处理方式、可能失败环节。**纸面练习只产出设计，不填写虚构的系统成绩。**

## 5. 可选运行实验与验收指标

未来在已授权、隔离环境中实践时，先固定资料、模型、分块和测试集，每轮只改一个变量。以下为教学配置，不是官方最佳参数：

1. 基线：Top 5、相似度阈值 0.2、向量权重 0.3，不加重排
2. 实验一：只增加与题目目标日期匹配的元数据条件
3. 实验二：在实验一基础上只增加重排

不要同时换模型、改分块和调检索，再把全部改善归功于一个参数。

| 指标 | 口径 |
| --- | --- |
| Hit@5 | 六道可回答题中，前五条至少含一条标准证据的题目比例 |
| 证据完整率 | 六道可回答题中，全部必要证据均被召回的比例 |
| 错版本回答数 | 答案使用了不适用于目标日期的材料的次数 |
| 引用支持情况 | 每条关键结论是否得到对应引用支持 |
| 无答案识别 | 两道缺失信息题是否正确说明证据不足 |
| 耗时与费用 | 实际请求耗时、模型调用成本；纸面练习无法测量 |

先分别看检索与回答，避免用一个总分掩盖原因。八道题仅用于初查；上线前扩充已授权、脱敏的真实问法，覆盖表格、长文档、冲突版本与权限，由业务风险决定门槛。

## 6. 限制和版本提醒

- 检索过滤不能独自承担访问控制，应在服务端校验身份、访问范围和越权场景
- 有引用不等于结论正确，要逐条验证支持关系
- 内部文档上传前确认授权、传输目的地、保留期和脱敏；凭据不得写进公开仓库
